# Hanpan changes to PhotoCraft

Built from PhotoCraft (https://github.com/storytold/photocraft), by the ArtCraft team, at the commit pinned in `pins.json`.

- window.photocraft page control API: upstream PR #9345 (storytold/photocraft), plus requests made before the app runs waiting for it (and, if the app cannot start, rejecting with the reason instead of waiting forever, with `openFile` returning false), plus captureDownloads/files/readFile ported from VectorCraft's web API, plus `app.save` writing through the browser download (or the page's capture) on the web, plus requests sent after the app has stopped rejecting with "The editor has stopped" (no app name: Hanpan shows a rejected request in its AI panel), plus `app.exportImage {format: "png"|"jpeg", maxSide?, quality?}` returning the document's composite as `{dataBase64, width, height, format}` without writing a file or touching the document, the status line or the notices.
- Korean text: NanumGothic Regular (OFL-1.1, from craft-fonts) in fonts/manifest.txt at the site root, which the web build fetches as the Hangul fallback.
- Brand: the ArtCraft name, the Discord and getartcraft.com links and their Help-menu entries are removed (code and translations); About carries the plain credit "Based on PhotoCraft by the ArtCraft team (MIT or Apache-2.0), modified for Hanpan." The product name PhotoCraft itself stays in the standalone app, in About and in the notices; inside Hanpan the rest of the chrome calls the app by Hanpan's name (see "App name" below).
- Embedded mode: with `embedded=hanpan` in the page address, Open, Open Recent, Close and Close All are off and hidden, New works only until the first document exists, and a file dropped off the canvas while a document is open is not opened as another document; without it the app is unchanged.
- The PC's fonts (embedded mode): the font menus end with a section "이 PC의 글꼴" listing the fonts installed on the PC, read with the browser's Local Font Access API (`window.queryLocalFonts()`) when a font menu first opens; a family picked there has its files read and added to the app's fonts, and the text set in it is drawn again once they arrive (as a served font is). The page API's `photocraft.request('fonts.local', {family?})` does the same for the host. The host must allow the `local-fonts` permission for the app's frame.
- A painting tool pressed with no layer chosen (every layer deselected, as a Move-tool click on the pasteboard does) does not start, and the status line asks for a layer in the interface language ("레이어를 먼저 고르세요. 레이어 패널에서 그릴 레이어를 누르세요.") instead of the engine's "command `paint.stroke` is not available right now: no active layer", which the status line no longer shows from any path.
- Status line (W3): the engine's developer wording never reaches it. "command `image.autoTone` is not available right now: the active layer has no pixels" reads as the command's name and what to do in the interface language ("자동 톤: 지금은 할 수 없습니다. 그림(픽셀)이 있는 레이어를 고르세요. 문자·모양 레이어에는 쓸 수 없습니다."), a reason with no hint is left out, a disabled shortcut says the same instead of "{label} is not available: {reason}", and any other error still in English in another language reads "이 작업을 하지 못했습니다." The original text goes to the browser console.
- The PC's fonts and the class filter (W5): a family of the PC is classed by its name (Serif, Sans Serif, Monospace, Script, Handwritten, Blackletter, Decorative, Slab Serif), so picking a class lists the PC's fonts of that class under "이 PC의 글꼴" instead of "이 필터와 일치하는 글꼴이 없습니다"; their names line up with the app's font names.
- Panel tabs (W13): the empty bar left of a panel group's menu is narrower (16 pt), so the Color group's tab names are whole in Korean and Vietnamese ("그레이디언트", "Họa tiết") at 1366 and 1920 wide.
- Hanpan themes (embedded mode): two themes, Hanpan light and Hanpan dark, with the colours of Hanpan's word processor (menu bar #ffffff / #252525 with the ribbon's #d9d9d9 / #555555 line under it, status bar #f3f4f6 / #252525, panels, pasteboard #e6e6e6 / #2b2b2b, text, borders; accent #A3449E). Inside Hanpan the app wears only these: the page address's `theme=light|dark` sets the first frame (the page itself is painted the matching pasteboard grey before the app starts), and the page API's `photocraft.request('hanpan.theme', {mode: "light"|"dark"})` switches at once without touching the document. `hanpan.status {}` answers `{mode, uiFont}`. Window › Theme and Darken/Lighten Interface are hidden there, and `ui.set {theme}` is refused; standalone, both methods are errors and the app's themes are unchanged.
- Dock gap (Hanpan themes): the 4 pt gap the docking layout leaves between the canvas's icon rail and the right dock (and between dock columns) is filled with the menu bar's colour (#ffffff / #252525), so the dock's own border (#e3e6ea / #3a3a3a) is the only line there; before, the window's near-black clear colour showed through as a thick black bar. Other themes paint nothing there, as before.
- UI font (embedded mode, Korean interface): with `lang=ko` in the page address the interface's Hangul is drawn with the PC's own face (Windows Malgun Gothic, Mac Apple SD Gothic Neo); any other interface language keeps the served fonts in the order its script asks for, and neither reads the PC face nor waits for it. It is read as the page starts, by its PostScript names (`queryLocalFonts({postscriptNames})`: MalgunGothic and MalgunGothicBold, AppleSDGothicNeo-Regular and -Bold), without listing every font first; the host must allow `local-fonts`. The first frame waits for it under the loading text, at most 1.5 s (also when the page clock does not move: the pauses themselves are capped); past that, or when it cannot be read, NanumGothic draws Hangul as before and the face replaces it when it arrives (a PC that does not give the face by PostScript name is read through the font list as before). Latin text stays Inter, sizes are unchanged. `hanpan.status` reports the face drawing Hangul as `uiFont`, and `uiFontSteps` (when each step of reading it happened, ms since the page started) for release checks.
- App name (embedded mode): the chrome (menu bar, title, panels, dialogs, start screen, status line, engine messages) shows no PhotoCraft name or mark; texts that named it read "AI 포토" in Korean and "AI Photo" in other languages, the default new-document preset has no app name. Help › About keeps the original name, its product line and the credit; standalone is unchanged.
- Licences: the licence texts the upstream NOTICE and ATTRIBUTION.md name (fonts, icons, word list, face-detection weights, translations, brand terms) ship in the site at the paths those files give.

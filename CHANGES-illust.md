# Hanpan changes to VectorCraft

Built from VectorCraft (https://github.com/storytold/vectorcraft), by the ArtCraft team, at the commit pinned in `pins.json`.

- Korean text: NanumGothic Regular (OFL-1.1, from craft-fonts) added to the fonts the web build fetches at startup (crates/text/web-fonts.txt), so Hangul has a fallback.
- Brand: the ArtCraft name, the Discord and getartcraft.com links and their menu entries are removed (code and translations); About carries the plain credit "Based on VectorCraft by the ArtCraft team (MIT or Apache-2.0), modified for Hanpan." The product name VectorCraft itself stays in the standalone app, in About, in the notices and in the file extension `.vectorcraft`; inside Hanpan the rest of the chrome calls the app by Hanpan's name (see "App name" below).
- Embedded mode: with `embedded=hanpan` in the page address, Open, Open Recent, Close and Close All are off and hidden, New works only until the first document exists, and a file dropped off the canvas while a document is open is not opened as another document; without it the app is unchanged.
- The PC's fonts (embedded mode): the font menus end with a section "이 PC의 글꼴" listing the fonts installed on the PC, read with the browser's Local Font Access API (`window.queryLocalFonts()`) when a font menu first opens; a family picked there has its files read and added to the app's fonts, then is applied (the canvas, PNG export, and SVG export as outlines or with the font embedded as `@font-face` use it like any other font; plain SVG text names the family, which a viewer without that font replaces). The page API's `vectorcraft.request('fonts.local', {family?})` does the same for the host. The host must allow the `local-fonts` permission for the app's frame.
- Status line (W3): "command `object.group` is not available right now: nothing selected" reads as the command's name and the reason in the interface language ("그룹: 지금은 할 수 없습니다. 선택된 항목이 없습니다."), without the command's id; a reason with no translation is left out, and the engine's other errors about a command read "이 작업을 하지 못했습니다." The original text goes to the browser console.
- Font menu samples (W5): a font without the selected text's characters shows "가나다라" (Korean) or "Mẫu chữ" (Vietnamese), or "AaBbCc" when it lacks those letters too, instead of the English word "Sample".
- Hanpan scheme (embedded mode): Hanpan light and Hanpan dark, with the colours of Hanpan's word processor (menu bar #ffffff / #252525, panels, pasteboard #e6e6e6 / #2b2b2b, text, borders; accent #3E9150). Inside Hanpan the app wears only these: the page address's `theme=light|dark` sets the first frame (the page itself is painted the matching pasteboard grey before the app starts), and the page API's `vectorcraft.request('hanpan.theme', {mode: "light"|"dark"})` switches at once without touching the document. `hanpan.status {}` answers `{mode, uiFont}`. The app's own theme choices do not override it there; standalone, both methods are errors and the app's themes are unchanged.
- UI font (embedded mode): the interface's Hangul is drawn with the PC's own face (Windows Malgun Gothic, Mac Apple SD Gothic Neo), read at startup through the PC fonts path (`window.queryLocalFonts()`, the host must allow `local-fonts`); until it arrives, or when it cannot be read, NanumGothic draws it as before. Latin text stays Inter, sizes are unchanged. `hanpan.status` reports the face drawing Hangul as `uiFont`.
- App name (embedded mode): the chrome (app bar, menus, panels, dialogs, Home screen, status line, built-in preset, profile and format names, the page's loading and failure texts) shows no VectorCraft name or mark; texts that named it read "AI 일러스트" in Korean and "AI Illustration" in other languages, the Home screen says what to do ("새 그림을 만들거나 파일을 여세요") instead of the name and tagline, and links out of the app don't open. Help › About keeps the original name, its credit and licences; the file extension `.vectorcraft` is unchanged; standalone is unchanged.
- Licences: the licence texts the upstream NOTICE and ASSETS.md name (fonts, icons, brand terms) ship in the site at the paths those files give.
